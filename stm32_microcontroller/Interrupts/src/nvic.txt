NVIC (Nested Vectored Interrupt Controller) is the part of an ARM Cortex-M microcontroller that manages interrupts and tells the CPU which interrupt to handle.
Think of it as the traffic controller for interrupts:

Hardware Event
     |
     |
   	NVIC
     |
     |----- Which Interrupt? 
     |----- Is it enabled?
     |----- What is the priority?
     |----- Which ISR should run?
     			|
     			|
     	    CPU -> ISR
     	    
For example:

Button Pressed -> NVIC receives interrupt -> NVIC tells CPU -> CPU pauses current code -> button_isr() runs -> CPU returns to previous code



The key thing to rememer:
NVIC is the hardware that manages interrupts between peripherals and the CPU on ARM Cortex-M processors.
