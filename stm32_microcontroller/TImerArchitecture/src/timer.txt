The 6 registers in timer:
1. PSC: How fast does the counter run?
2. CNT: What is the current count?
3. ARR: When does the counter reset?
4. CR1: Is the timer running?
5. DIER: Should an event generate an interrupt?
6. SR: Did the event happen?


1. PSC
- PSC slows down the timer clock before it reaches the counter.

Writing PSC in C:
TIM2->PSC = 7199; // We are writing the value 7199 into TIM2 Prescaler Register.

Imagine if the timer receives 72 MHz, it is way too fast to count directly to many application, 
so we use PSC to slow down the timer counter counts. PSC (prescalar) derives a slower clock for a 
timer counter.

2. ARR
- 72 MHz -> PSC = 7199 -> 10 kHz counter clock -> CNT counts: 0, 1, 2, 3, ..., 9 -> ARR reached -> CNT Resets-> 0
which happens every 1 ms

So, CNT at 0 says event here. So, at 9-> reaching ARR creates an update event. 
When the counter reaches the programmed limit, the timer generates an update event. 

Think of it as:
"My timer period is finished." That event can then be used to do something. 

PSC -> Counter -> ARR
We use PSC to turn the 72 MHz timer clock into a 10 kHz counter clock. Then the counter counts from 0 to 9, 
which takes 1 ms, and reaching ARR generates an update event. 

And that is why:
           72 MHz % 7200 % 10 = 1 kHz OR equivalently: T = 1 / 1000 = 1 ms where 1000 is 1 kHz.
